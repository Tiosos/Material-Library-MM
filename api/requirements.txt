# Pinned on purpose: CI and a local install must resolve the same wheels, and every pin here
# has a reason.
#
# fastapi 0.162.0 + starlette 0.52.1: the MCP server needs mcp 2.3.0, which requires
# sse-starlette>=3.0.0, which requires starlette>=0.49.1. The previous pin (fastapi 0.115.6 +
# starlette 0.41.3) capped starlette below 0.42, so the two could not share one environment
# (docs/t2-progress.md, MCP step 0). Both upgrades are in one commit on purpose: the API suite
# and the MCP suite are installed together and must be verified together.
# fastapi 0.162.0 depends on opentelemetry-api directly, so it is pinned rather than avoided.
# psycopg 3.3.6 is the first release of the 3.3 line with the binary wheels this project needs;
# psycopg-pool 3.3.3 is the version that ships with it.
# pytest and httpx are test-only: FastAPI's TestClient speaks HTTP through httpx.
